# 照片 Photos

## 診所實景（本院照片）
- `exterior.jpg`: 診所正面外觀。放在首頁「交通指引」與兩個部門頁的「聯絡資訊」，方便病人抵達時辨認。原始照片經過清理，並校正為正面角度。

照片另有較小的版本與 WebP 格式（`-460`、`.webp`），讓手機載入更快。
**更換照片時**，請用相同檔名上傳 `.jpg`，並刪除同名的 `.webp` 與 `-460` 檔案，或用新照片重新產生這些檔案；否則支援 WebP 的瀏覽器仍會顯示舊照片。

## 插畫示意圖（非本院實景）
其他頁面上的醫師與病人插畫放在 `assets/images/generated/`，網頁上標示「示意圖」。提示詞與檔名見 `assets/images/generated/PROMPTS.md`。

先前首頁「診所環境」的候診區照片已移除，該區改為「交通指引」。
