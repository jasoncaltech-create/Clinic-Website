## 本一牙醫診所頁面的兩個照片位置
目前皆為暫用照片，待新照片備妥後更換（`dental.html` 內以 `✏️` 註解標示更換方式）：
- 主視覺（滿版背景）：暫用 `dental-room.jpg`。新檔名 `dental-hero.jpg`，橫式，建議寬 2400、高 1350 以上；畫面左側三分之一宜單純，供白色文字疊放。
- 診療項目旁：暫用本院實景照 `interior.jpg`（掛號櫃台與候診區）。新檔名 `dental-services.jpg`，比例約 8:7，建議寬 1600、高 1400 以上。

`dental-hero.jpg` 與 `dental-services.jpg` 預計為 AI 生成的示意圖（非本院實景，畫面中的人物亦非本院醫師、員工或病人）。
上傳後請在此補上一行說明（例如：`dental-hero.jpg`: AI 生成示意圖，生成日期與使用工具），網頁上並須保留「示意圖」標示。

換照片時，用相同的檔名上傳即可。若改用本院實景照片，可刪除網頁中的「示意圖」標示（搜尋 `photo-note`）。
