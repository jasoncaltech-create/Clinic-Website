# 照片 Photos

## 診所實景（本院照片）
- `exterior.jpg`: 診所正面外觀。放在每一頁的「聯絡資訊」，方便病人抵達時辨認。原始照片經過清理，並校正為正面角度。
- `interior.jpg`: 掛號櫃台與候診區（首頁「診所環境」，捲動時照片會放大）。原始照片經過裁切、白平衡與亮度調整。

每張照片另有較小的版本與 WebP 格式（`-460`、`-640`、`.webp`），讓手機載入更快。
**更換照片時**，請用相同檔名上傳 `.jpg`，並刪除同名的 `.webp` 與 `-460` / `-640` 檔案，或用新照片重新產生這些檔案；否則支援 WebP 的瀏覽器仍會顯示舊照片。

## 生成示意圖（非本院實景）
其他頁面上的情境圖片放在 `assets/images/generated/`，網頁上標示「示意圖」。提示詞與檔名見 `assets/images/generated/PROMPTS.md`。

先前使用的圖庫照片（含人物）已移除。
