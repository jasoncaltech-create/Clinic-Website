# 照片 Photos

## 診所實景（本院照片）
- `exterior.jpg`: 診所正面外觀（首頁主視覺）。原始照片經過清理，並校正為正面角度。
- `interior.jpg`: 掛號櫃台與候診區（首頁「診所環境」）。原始照片經過裁切、白平衡與亮度調整。

## 情境示意照（圖庫照片，非本院實景，網頁上標示「示意圖」）
- `child-care.jpg`: 本一診所頁面上方。來源：美國疾病管制與預防中心（CDC）Public Health Image Library，經 rawpixel 提供，公有領域 (CC0)。
- `senior-care.jpg`: 本一診所「診所介紹」。來源：StockSnap，CC0（可免費商用，無需標示來源）。
- `dental-room.jpg`: 本一牙醫診所頁面上方。來源：StockSnap，CC0。

換照片時，用相同的檔名上傳即可。若改用本院實景照片，可刪除網頁中的「示意圖」標示（搜尋 `photo-note`）。
